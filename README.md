# powerprobe

This board is intended to support side-channel analysis. It powers the target device and provides 20x amplification of the signal measured across a low-side shunt resistor.
 
See the [schematic](https://github.com/cpey/powerprobe/blob/main/images/powerprobe.pdf) for additional details.
